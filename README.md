# Sajda

Sajda is a modern Islamic mobile application designed to support daily spiritual routines.

## Features
- Prayer Times
- Qibla Direction
- Daily Ayah & Hadith
- Favorites
- Notifications

## Tech Stack
- iOS: SwiftUI (MVVM)
- Android: Kotlin + Jetpack Compose
